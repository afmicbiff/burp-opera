# Burp Opera 🐸🎩

A funky, wild one-button web game. You're a frog in a top hat: **hold** to puff up your throat, **let go** to burp at the singing NPCs at the matching height.

## Play
Open `index.html` in any modern browser (desktop or phone).

## Features
- 100 levels, boss squads every 60 s, power-ups, 20 playing fields
- Many NPC casts (Opera Ghost, Kitchen Chaos, robots, space, farm, sea, reef, UFOs, wild cars…)
- Classic 2D, 3D, and 8-bit views
- Difficulty modes: Little Burper, Teen, Adult, Crazy Expert (with parent lock)
- Frog and hat colors, boy/girl frog, unlocks up to level 50

> Note: the world leaderboards only work when the game runs as a claude.ai Artifact. Opened anywhere else, the game still plays, just without the online boards.
